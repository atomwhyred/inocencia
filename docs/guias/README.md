# Guías de inocencIA

Tutor sin internet para niños cubanos de 1.º a 6.º grado. Estas guías son para las familias que quieren usar la
app. Se pueden compartir sueltas.

1. [¿Qué es inocencIA?](01-que-es-inocencia.md): para quién es y qué queremos lograr.
2. [Descargar e instalar](02-descargar-e-instalar.md): qué bajar del canal, qué modelo elegir y dónde copiarlo.
3. [Primeros pasos](03-primeros-pasos.md): PIN, archivos, perfiles y prueba de velocidad.
4. [Cómo lo usa el niño](04-uso-para-ninos.md): tutor, libros, tarjetas, medallas, descansos y modo batería.
5. [Jugar](05-jugar.md): en un teléfono o entre varios, sin internet.
6. [Problemas y soluciones](06-problemas-y-soluciones.md): qué hacer si algo falla y cómo pedir ayuda.

Las capturas de las guías están en la carpeta [img/](img/).

**Resumen rápido:** instala el `.apk` → copia el modelo `.gguf` y `knowledge.db` a
`Android/data/com.inocencia.app/files/` y los PDF a `.../files/libros/` → **Zona de padres → Archivos → Detectar**
→ crea el perfil del niño → **Tutor**.
